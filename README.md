# LogicTrans | Cotizaciones de maquinaria pesada

LogicTrans es una aplicación web para una empresa salvadoreña de alquiler de maquinaria pesada. Los clientes pueden consultar la flota, solicitar cotizaciones y darles seguimiento. El administrador puede gestionar los equipos y actualizar el estado de las solicitudes.

Proyecto del **Desafío Práctico II de Desarrollo Web I (ESEN, 2026)**.

[Sitio publicado](https://jesswiz.github.io/DesafioPractico1/)

## Registro e inicio de sesión

1. Abre el sitio y selecciona **Ingresar**.
2. Elige la opción de registro y completa el formulario.
3. Inicia sesión con tu correo y contraseña. Las cuentas nuevas se crean con el rol de cliente.

## Cómo probar la aplicación

| Rol | Qué puedes probar |
| --- | --- |
| Visitante | Explorar el catálogo y filtrar los equipos disponibles. |
| Cliente | Elegir un equipo disponible, enviar una solicitud de cotización y consultar su estado en **Mi panel**. También puedes cancelarla mientras esté pendiente. |
| Administrador | Agregar o editar equipos, revisar las solicitudes y cambiar su estado a **en evaluación**, **aprobada** o **rechazada**. |

## Tecnologías

HTML, CSS y JavaScript. Firebase Authentication gestiona el acceso y Cloud Firestore almacena los equipos y las solicitudes. El sitio está publicado en GitHub Pages.
